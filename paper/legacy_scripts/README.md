# Original research scripts

These retain the original algorithm, seeds and model settings and require
proprietary input data. They are included for logic review, not quickstart.
The two historical gas scripts are unchanged and superseded by the Methods
implementations in ../corrected_scripts/ and zonerel.recalibration.
run_gas_proxy_sensitivity.py is an obsolete exploratory gas_proxy_index
implementation; it does not produce the current S20b table.
See PATH_CHANGES.md for permitted local-path substitutions in other scripts.
